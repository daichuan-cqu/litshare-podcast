# Litshare — Protein Degradation English Corner

A dual-dialogue English podcast on targeted protein degradation: PROTACs, molecular glues, and E3 ligases. Hosted by David and Alex. Each episode unpacks one paper in plain spoken English, at 0.8x speed for English learners.
